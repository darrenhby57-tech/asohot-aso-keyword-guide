What Data Does the Free ASO Keyword Tool Show?

Search an app to see the keywords it already ranks for. Each row in the keyword table shows five metrics:

MetricWhat it means
KeywordsThe search terms this app already ranks for.
RankingThe app's current position in the store results for that keyword.
Value ScoreAn overall score for the keyword, modeled from multiple data points.
VolA search-heat index. Vol is a search popularity index, not the exact monthly search volume.
ResultsHow many apps compete for the keyword. A higher number usually means stronger competition.
